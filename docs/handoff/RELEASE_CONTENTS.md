# GitHub发布附件

标签：v0.3.0。主分支保存可克隆的当前源码、文档、美术和资源，无需Git LFS。

- `ApocalypseGame-v0.3.0-mac.zip`：已验证的Mac试玩，不是iPad或Windows安装包。
- `ApocalypseGame-v0.3.0-handoff-full.zip`：完整交接工程、最新交接文档、独立Mac运行时和历史资源去重归档。历史归档中的恢复索引记录172种文件内容的原来位置及校验值。
- `SHA256SUMS.txt`：附件的SHA-256校验值。
- `HANDOFF_WINDOWS.md`：交接文档副本；以仓库docs/HANDOFF_WINDOWS.md为维护入口。

Windows正常继续开发只需克隆仓库并安装官方Ren'Py SDK；下载完整交接ZIP可获得额外历史资源和Mac运行时备份。SDK和发行ZIP不塞入Git提交历史。旧存档留在Mac本地，不上传到仓库或附件。
