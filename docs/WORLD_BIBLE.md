## 1. 设定状态与创作基线

### 1.1 状态约定

| 标记 | 含义 | 开发时的处理 |
|---|---|---|
| **已确定** | 用户明确指定，或既有讨论已经确立的基础设定 | 后续剧情和机制应保持一致；修改需明确记录 |
| **暂定** | 已有建议、参考数值或规划草案，尚未定稿 | 可用于原型估算，不作为不可变世界事实 |
| **待讨论** | 尚缺决定、核算或支撑条件 | 不擅自填入具体型号、库存、能力或剧情结论 |

每个小节的状态说明覆盖该小节正文；混合状态用表格逐项注明。「开发者内部」与「玩家可知」是信息权限，独立于设定状态。已确定的秘密也不能直接写进序章旁白。

### 1.2 核心方向

**已确定：** 以末日生存模拟、Galgame 式文字冒险、多分支选择与社会群像相结合，重视资源约束、人物关系与人性冲突。主角的起点是保护四口之家，故事随后逐步拓展到邻里与社区。

社会不会因灾难一夜消失。政府、军警、医护与工程人员持续应对；失序来自长期危机对交通、供应、维护和组织能力的累积冲击。人物的努力可能有效，也可能遭遇能力边界。

**叙事基线：** 玩家是普通家庭的一员，掌握有限信息；世界和其他居民会独立行动。选择改变资源、处境与关系，不提供始终正确的唯一答案。合作有条件、有代价，社区发展保留分支。

## 3. 四口之家与返乡动机

### 3.1 核心人物

**已确定：** 家庭人口为四人：主角、伴侣、父亲、母亲。主角与伴侣是一对在沪海市工作的情侣，父母长期住在庐州市老家。四人都对极端灾难有很强的畏惧、敬畏与风险意识。

他们没有提前知道感染事件的秘密。更早行动的原因是长期防灾习惯：在信息尚不完整、潜在后果严重时，先做能够负担的准备。既有住所和储备降低了返乡门槛，但不消除工作、收入与交通上的代价。

### 3.2 返乡主线

**已确定：** 情侣在沪海听到异常风声后，主角先打电话让父母在庐州准备食品、生活物资与材料；两人也在沪海采购、整理行李，驾驶自己的新能源轿车带着物资返乡，入住父母的城郊住宅。返乡后仍有几天采购和准备窗口，随后危机全面暴发。

采购、出发时机、路线和帮助他人的选择会影响到家时间、资源、信息与关系。序章顺序是主线骨架，具体分支不等于每个周目必须在同一时刻完成同一行动。

## 4. 家庭防灾历史

### 4.1 V0.4 新增的确定背景

**已确定：** 2030年以前，庐州市及周边曾有一段较为频繁的小规模地震活动。持续的震感让一家人认真面对极端灾难和基础设施中断的可能，于是购置并修缮这套住宅，最初用于地震应急避难与长期居住。

住宅的地下室储备、备用能源和部分应急设施在感染危机前就已存在。2030年的准备是在既有防灾基础上追加采购和调整生活方式，而非六天内凭空建成完整避难所。

这是架空历史事件。叙事不能把小地震写成“大地震必然即将发生”的准确预言，也不能用“独栋比高楼天然安全”替代房屋的选址、结构、施工和修缮条件。地下室承担储藏功能，不设为震时必然安全的躲避地点。

### 4.2 历史时间线草案

**以下年份全部暂定；已确定的是地震活动 → 防灾意识 → 购房修缮 → 建立储备 → 2030年返乡的因果顺序。**

| 暂定时间 | 草案事件 |
|---|---|
| 2027年 | 庐州周边频繁轻微地震，家庭开始关注应急避险 |
| 2027年下半年 | 父母系统了解防灾，讨论备用居所 |
| 2028年 | 购置住宅，安排评估与修缮 |
| 2028—2029年 | 逐步改善设施、安装能源系统 |
| 2029年 | 建立并轮换食品、水、药品与工具储备 |
| 2030年 | 情侣预警、返乡，家庭追加危机采购（年份已确定） |

**暂定修缮项目：** 专业房屋安全评估及必要结构修缮，储物架固定、重型家具防倾倒、应急照明、灭火器与烟雾报警器、基本医疗用品、备用饮水、应急工具、网络设备备用电源。具体施工内容、费用和完成状态待讨论。

### 4.3 选择城郊与历史呈现

**暂定动机细节：** 独立空间便于储物和改造，附近有开阔区域，仍可利用城市医疗与商业服务，住宅平时也有居住价值。产权、购置方式和家庭经济来源待讨论，不默认周边土地都归家庭所有。

**已确定的呈现原则：** 家庭防灾历史在第一阶段通过探索、照片、文件、对话与回忆逐渐展现。

**暂定桥段：** 序章第4天探索地下室时发现旧修缮记录、施工照片和家庭应急清单，触发短回忆。文件年份随历史时间线定稿；不能先把“2028年修缮记录”写死。

防灾准备提供较好的起点，但地震准备无法独立解决长期感染风险、医疗、生产、治安和社区关系问题，这种能力边界应贯穿后续剧情。

## 6. 物资、能源与技术设备

### 6.1 物资来源与管理

**已确定：** 开局物资由防灾常备储备、父母接到电话后的追加采购、情侣从沪海带回的用品共同构成。库存有限，不足以自动覆盖全年生存。

| 类别 | 内容方向 | 状态 |
|---|---|---|
| 防灾常备 | 食品、瓶装水、照明电池、急救与卫生用品、备用衣物、工具、收音设备 | 已确定有常备物资；逐项数量与状态待讨论 |
| 危机采购 | 米面粮油、罐头、易储食品、饮水、日用品与改造材料 | 已确定有追加采购；具体品类和数量受选择影响 |
| 资源管理 | 保质期、轮换、重量、体积、储藏条件 | 暂定系统细节 |

饮用/烹饪用水与清洁、洗衣等生活用水分别管理。作为**暂定算例**，若饮用及基本烹饪用水按每人每日3L，四人30天需要360L；这只是库存估算，不是家庭全部用水定额或已确定初始库存。

### 6.2 能源系统

| 项目 | 状态 | 设定 |
|---|---|---|
| 光伏 | 已确定 | 家庭已有光伏设备 |
| 固定储能 | 已确定 | 标称30kWh，用于停电时保障基本生活 |
| 光伏总规模 | 暂定 | 12kWp |

| 电池类型 | 暂定 | V0.3采用磷酸铁锂作为技术基线，具体设备待选 |
| 安装历史 | 暂定 | 修缮中逐步安装，储能从较小容量扩展至30kWh |
| 配套设施 | 暂定 | 家用充电、应急照明、小型UPS、宽带与移动通信 |
| 储水设施、开局电量、供电负载 | 待讨论 | 尚无定稿参数 |

容量kWh、装机功率kWp、瞬时功率kW和每日发电量不能互相替代。**暂定算例：** 30 × 90%可用比例 × 92%转换效率 = 24.84kWh交流可用电量；若每日消耗6kWh、无补充，约4.14天。比例、效率和6kWh日耗电都不是定稿。

**设计约束：** 停电运行要在设备设定中明确离网/备用供电能力；不能默认任何并网光伏停电后仍能使用。发电受季节、天气、遮挡和设备状态影响；汽车补能与生活负载竞争有限电量。储能能缓冲停电，不能无限制造能源。

30kWh是已确定的家庭配置，但购房、修缮、能源设备的资金来源尚未完成设定。不能因此默认家庭富裕或序章资金无限。

## 7. 灾难起源与感染规则

### 7.1 开发者掌握的真相

**已确定，开发者内部：** 全球危机起源于一次实验室事故，泄漏的是虚构神经嗜性病原体，影响活人的神经功能和行为。事故初期未被完整认识，感染事件逐渐出现于多地。序章不能公开泄漏真相。

| 规则 | 状态 | 内容 |
|---|---|---|
| 感染对象 | 已确定 | 人类，动物不会感染 |
| 传播途径 | 已确定 | 体液传播，不擅自新增空气传播 |
| 潜伏期 | 已确定 | 2天至6个月以上；6个月不是上限 |
| 天然免疫 | 已确定 | 全球约5%人口具有天然免疫/抵抗能力 |
| 非免疫感染者结局 | 已确定 | 一旦确立感染，最终转化 |
| 治疗 | 已确定 | 早期缺乏可靠治疗手段，难以治疗 |
| 变异 | 已确定的当前范围 | 暂不发生显著变异；后续若改需另行讨论 |
| 感染者本质 | 已确定 | 活体神经行为严重异常，不是死人复活 |

5%天然免疫是人群设定，不代表剩余95%已经感染或会无暴露自动转化。非免疫者被感染后的转化结局，与实际暴露、感染概率和社会总感染人数分别处理。四名家人及具体NPC是否免疫尚未确定。

### 7.2 未定的感染与检测边界

**待讨论：** 潜伏感染者何时具有传染性、何种体液接触会构成感染、检测准确性与可得性、转化前症状、潜伏期分布及免疫者识别方式。不填入未经确认的检测窗口或接触概率。

潜伏期与传染期分别描述。长潜伏期带来识别、流动和长期信任问题，但不能单凭“潜伏很久”就断言一定高速传播或所有封锁无效。剧情通过信息滞后、多地事件、识别困难与资源承压展现控制边界。

**叙事表达约束：** “病毒聪明”可以是人物比喻，客观旁白不能赋予病原体意识或策略意图。本文为虚构世界规则，不把这一组合描述为已发现的现实疾病。

## 8. 感染者代谢、运动与感知

### 8.1 生理与能量

**已确定：** 感染者仍需氧气、水和能量，具备杂食能力，能吃普通食物补充能量，也可能攻击人或动物。动物不感染不代表不会被攻击。肌肉、骨骼和器官受物理与生理条件约束；创伤、失血、脱水、饥饿和内脏损伤会影响活动并可能致死。

能量无法得到补充、消耗殆尽并发生生理衰竭时，感染者最终死亡。不能把高代谢、持续奔跑和长期不进食同时写成常态；消化与排泄也属于其活体生理过程。

### 8.2 运动阶段

**已确定的方向：** 初期强运动、强消耗，随后随饥饿、脱水与损伤逐渐衰弱。阶段划分用于表现趋势，具体持续天数和运动参数待讨论。

| 阶段 | 运动与行为 | 能量约束 |
|---|---|---|
| 初期 | 高度兴奋、攻击性强，短时间快速奔跑 | 高代谢，无法持续无限冲刺 |
| 中期 | 多以步行为主，偶有短冲刺 | 资源不足和身体损伤累积 |
| 晚期 | 行动迟缓，生理衰竭 | 长期缺水缺食最终死亡 |

不顾疼痛造成的危险性不等于无限体力。旧转化者可能衰弱，但长潜伏感染者仍可能陆续转化，因此等待数月不能保证外界绝对安全。

### 8.3 感知

**已确定：** 以声音作为主要注意触发方式，视觉辅助定位。不设超自然听力。距离、遮挡、天气与背景噪声影响反应。

**暂定机制：** 金属碰撞、汽车、无人机与机械作业可能吸引感染者；突发声与持续背景声的反应不同。具体感知距离、噪声阈值、目标切换与追踪时间待讨论。

## 9. 社会渐进失序

**已确定：** 政府与军警尽早设立封锁线、隔离和街区管制，医院开展研究与救治。这些措施能够迟滞危机，不意味着完全无效。国家及公共服务体系不会突然全部消失，各地响应与基础设施状态不同。

公共交通较早停运或受限，随后零售和物流供应承压；数月后的部分地区可能出现持续水、电、网络中断。停运可能源自管制、人员不足和安全风险，不等于设备报废；超市断供也不等于全国没有食品。

### 9.1 参考演变表

**以下日期均暂定，以全面暴发日为起点，不是所有地区同步执行的倒计时。**

| 参考时期 | 社会状态 | 可能事件 |
|---|---|---|
| 暴发前 | 异常信号 | 零星消息、局部通报、谣言与个别管制 |
| 第1—14天 | 紧急响应 | 医院隔离、封锁街区、客运受限、抢购 |
| 第15—45天 | 供应链承压 | 物流延误、零售短缺、燃料限供、医疗紧张 |
| 第46—120天 | 局部设施失效 | 长期停电、供水不稳、通信故障、互助增长 |
| 第121—365天 | 长期重组 | 区域组织、社区自治、有限生产恢复 |

各系统分别变化：铁路可能停客运而继续运输救援物资；某些社区断水，附近工业设施仍有限运转。局部故障可更早发生，备用能力和维护让另一些地区持续数月甚至更久。

世界状态按区域、交通、供应、能源、通信及组织能力分别管理。军事、行政和社区组织可并存，人类组织不按单一善恶标签划分。

## 11. 社区关系与合作

**已确定，开发者内部：** 居民从陌生、猜忌逐步走向通力合作；前期不解释这条发展路线，第二阶段再逐步展开群像与合作的意义。合作规模、加入者与成败由人物、资源和选择影响。

### 11.1 初期猜忌

资源差异、感染风险与信息不足引发怀疑：有人担忧囤货，有人不愿公开库存，有人寻找帮助却遭到防备。不能把猜忌归结为某个阶层天生自私。

**暂定伏笔：** 邻居知道父母认真修缮过房屋；停电后家中仍有灯光，引起关注。母亲可能认识菜农、商铺或邻居，但关系不意味着无条件信任。这些既有建议需随NPC设计落实。

### 11.2 有限交换

**暂定事件方向：** 交换食品药品、维修设备、分享可靠信息、联合运输、照顾弱者。农户可能有生产资料而缺能源；年轻打工人可能有技术而缺住所和长期储备；家庭有储能但不能单独恢复公共供水。

合作仍可能争执或中断。一些居民离开，一些保持家庭独立，一些只进行临时交易。

### 11.3 稳定共同体

**已确定的发展方向：** 长期互动让部分人形成协作网络，涉及生产、供水、电力、医疗、运输、治安、设施维护和对外交流。不能一夜建立统一社区，也不能强制玩家成为领袖。

玩家可以成为普通参与者、技术提供者、协调者，或仅与共同体保持合作；不同周目可能出现较早互助、长期分裂或以独立家庭为主的结果。方向已确定不等于结局必然成功。

| 第31—90天 | 邻里与社会 | 群像、信任、合作与冲突 |
| 第91—180天 | 生产与重建 | 农业、能源、公共设施 |
| 第181—270天 | 秩序与共同体 | 分配、组织、对外关系 |
| 第271—365天 | 新的生活 | 长期能力、人物命运与结局 |

第二阶段指叙事逐步扩展到社区，不能写成第31天必然统一合作；生产恢复与关系发展可提前、延后或失败。

### 14.2 系统规划

**以下为暂定实现方向，不代表仓库已有这些功能。**

| 系统 | 对应设定与约束 |
|---|---|
| 时间与行动 | 昼夜、旅行、工作、疲劳及准备窗口 |
| 资源与储藏 | 数量、消耗、保质期、体积、常备与追加物资 |
| 家庭与健康 | 四人独立需求、情绪、行动、伤病和感染 |
| 移动与车辆 | 步行及其他交通方式、路线、能耗、载重、损耗 |
| 电力 | 光伏产量、储能状态、负载与车辆充电竞争 |
| 信息 | 新闻、传闻、可信度、通信和角色已知事实 |
| 地点与世界演化 | 区域设施、营业/管制状态、供应链和疫情 |
| NPC与社区 | 记忆、技能、资源、独立行为、信任及合作 |
| 剧情与结局 | 固定、条件、随机事件，长期状态与人物命运 |

NPC不会因玩家未访问而暂停生活。养殖场继续消耗饲料，公寓居民继续寻找资源，商店继续变化。可用群体状态、关键NPC和周期结算表达动态世界；不要求逐秒模拟上千人。
