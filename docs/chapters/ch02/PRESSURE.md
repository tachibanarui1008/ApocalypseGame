# 人物压力与活动恢复 V0.1

2026-10-14，用户要求为人物增加压力，活动及每天按时睡觉可适当减轻压力。适用于六位已命名角色；当前可玩教程仍仅操作原四人，林建平、许静宜在正式入住后的个体状态与六人日结尚待接入。

压力为每人独立0—100，越高越紧张，不能照搬饱腹/饮水“越低越危险”的方向。教程初始20、达到70显示暖色提醒；这些是可调整的游戏参数，不是医学量表。压力不代替具体情绪与剧情，不自动令人物开门、失控、感染或禁用行动。晚宁的院门事件仍由既定父母遇害分支触发。

## 当前教程参数与操作

| 项目 | 单人变化 | 时机 |
|---|---:|---|
| 每个上午/下午生活背景 | +3 | 完成一次行动 |
| 外出采购 | 额外+5 | 主角与真实同行者 |
| 留家清点/检查 | 额外+3 | 实际承担的人 |
| 休息 | −8 | 抵消本时段+3，净−5 |
| 阅读放松 | −12 | 抵消本时段+3，净−9 |
| 食物或饮水不足 | +8 | 晚间一次；两项不足不叠加 |
| 按时睡觉 | −6 | 晚间结算后结束一天，每人分别选择 |
| 当晚晚睡 | 0恢复 | 不额外虚构工作成果，也不自动补满其他需求 |

下午可给主角安排“阅读放松”，留家成员可选“读书”；占用一个正常行动时段，仍有饱腹、饮水、卫生消耗，不能边采购/施工边享受同一人的活动恢复。原有休息也能适度减压。默认夜间按时睡觉，晚间人物卡可分别切换“今晚晚睡”；点击结束当天后才应用睡眠恢复，打开盘点、重复载入或重算晚餐不再发放恢复。

所有变化夹在0—100，行动、晚餐、睡眠及剧情事件各自防重复。存档迁移给缺少压力字段的人补初始20，已有值保持；不回放历史工作或此前睡眠。已有晚间存档可继续本次结束一天动作，不能反复切换按时/晚睡刷恢复。

## 后续活动与剧情

已完成PREP-MEDIA后可选择一起看剧/电影，聊天、阅读、简单庭院活动与家人相处可作为后续活动。每次需要可用地点、时间、参加人和设备条件；只有参加者恢复，影音需要真实供电与可用文件，不能未下载就获得收益。参数由活动配置独立设置，陪伴可以缓解压力，不删除丧亲事实或一次治愈悲伤。

封锁、供应焦虑、枢纽失守与失去亲人可在正式日程中提高相应人物压力；当前提供`c2_stress_event`接口，按唯一事件ID与人物变化提交一次。第二章Day8—12完整剧情未接入，因此没有伪称这些压力事件已经在默认教程播出。压力与既有接应好坏结局分开；工程或娱乐不能把既定坏结局改成好结局。

## 已实现与边界

教程已接入个人压力条、详情说明、休息/阅读减压、每人晚间按时睡觉选择和一次睡眠恢复；没有新增体力。名字与人物设定另见[CHARACTERS](CHARACTERS.md)。完整六人个体结算、影音活动菜单和剧情压力强度仍待正式日程实现。参数集中在`game/ch02_demo.json`，资源费用与房屋容量保持原值。
