# 人物需求与家庭物资条 V0.6

当前教程四人各有独立的饱腹、饮水、卫生、压力（0—100），不设置体力。初始90/90/85/20。人物名字可打开详情，低于30显示暖色警示，目前不触发疾病或行动禁用。

每个上午/下午生活消耗18饱腹、25饮水、3卫生。工作额外消耗：步行采购按路线时长增加，驾车采购5/7/3，检查10/14/10，清点5/7/4。主角与同行者按主行动，留家者按自己的任务计算。休息仅有生活消耗。

下午可以安排主角或留家者洗漱：恢复35卫生，消耗6L用水。普通供水优先，停水时扣应急储水；水不足时按实际供给比例恢复。

晚间四人合计扣4人日口粮，每人恢复60饱腹；日饮水合计8L，每人恢复80饮水。食物和水不足时按供给比例恢复。工作只降低人物状态，首版不另扣额外工作口粮或额外饮水；后续可在独立配置中调节需求与补给。正常供水不扣应急水。卫生不会在晚间自动回满，电车仍按市电状态充电。

家庭食品、应急水、护理用品、燃油、电车电量、储能均显示条形、实际数量和消耗说明。参考刻度为演示基准，不是房屋容量；超出刻度时满条，数量仍完整显示。资金保留数值。

行动结果保存每个人的消耗及前后状态。完成行动和晚间结算均保持防重复记账。旧教程存档补充初始人物状态，不重放已经完成的行动、采购与结算。
