# 第二章《风暴前夜》设计基线 V0.1

确认日期：2026-10-09  
性质：已确认的玩法方向、首版内容清单与制作依据。不是完整逐句剧本，也不是已经实现的游戏。  
衔接依据：第一章B/C线现有正文、世界观资料、安全屋户型V0.5。

## 1. 章节定位

第二章把第一章的返乡叙事转为可操作的家庭准备。玩家每天分别安排四名家人在地图上采购、收货、维修、建设与互助，将有限的钱、时间、人手和运输能力转化为危机后的储备。

重点体验是：世界仍在运转，但可靠的机会正在减少。地图和数字提供判断依据，地点场景与家庭对话让每次判断有生活质感。

### 已确认的方向

- 第一章Day 12为正式爆发日。C线有9个完整准备日，B线有8个。
- 全程显示“距离危机正式爆发剩余：XX天”。倒计时是玩家信息，人物不准确预知日期。
- 四人分别排班；任务可以要求多人协作或指定人员条件。重型体力任务按用户设定要求男性参与，专业技术条件单独判断。
- 地图允许多站路线；近处可步行，远处或大宗采购需要车辆，消耗燃油或电量。
- 采用物资包采购，不逐件管理所有商品。
- 准备期正常供水、供电、联网；家庭储能保持满电。回家的电车夜间自动充满。
- 风险主要是秩序收缩与可规避的局部险情。首版不开放战斗。
- 章末中央广播宣布国家进入紧急状态，随后进入第三章。

## 2. 时间与两线衔接

剩余天数＝12－当前Day。Day 11显示1天；Day 12显示0天并播放章末事件。Day 12不再提供新的准备排班。

| 路线 | 第一章末尾 | 第二章完整行动起点 | 准备日 | 开场差异 |
|---|---|---|---|---|
| C | Day 2，18:10抵家 | Day 3，剩余9天 | Day 3—11 | 情侣先检查房屋；父母上午抵达、下午可排班 |
| B | Day 3，19:06抵家 | Day 4，剩余8天 | Day 4—11 | 四人已团聚，父母部分采购与储藏工作已完成 |

两线共同拥有既有防灾储备。B线追加物资较多，C线多一天准备时间；B线既往采购要从其对应的准备预算中计账，不同时赋予更多物资和未经扣减的完整资金。

C线父母的抵达事件不提供可重复领取的奖励。两线初始化分别执行一次；存读档、回看和进入共通剧情不重新发放库存。

开场家庭会议交代父母暂时收拢工作、参与准备。母亲的护理经验、父亲的餐厅采购与普通维修经验用于任务和对话，不赋予万能医疗或工程能力。

## 3. UI与每日循环

### 主界面布局

| 区域 | 内容 |
|---|---|
| 顶部 | 倒计时、上午/下午、天气、供水供电网络状态、重要供给消息 |
| 中央 | 区域地图、地点状态、已规划路线、队伍与车辆位置 |
| 侧边 | 资金、食品、应急饮水、医疗护理、卫生、燃油、储能、建材摘要 |
| 底部 | 四人排班、两车占用、待办与“确认执行” |
| 点选地点 | 可用任务、物资包、营业情况、时间成本和已知风险 |
| 点选安全屋 | 房屋分区、工程阶段、设备状态和储藏情况 |

食品与应急饮水同时显示库存和按当前家庭用量估算的支持天数。电力分开显示“市电正常”“储能电量”“备用系统测试状态”，不把电池满电误写为已经验证全部备用能力。

### 每日顺序

1. 早晨：处理到货与日期事件，显示新闻、天气和家庭建议。
2. 上午：安排全部队伍和留家任务，检查人员、车辆、时间、资金与材料，确认后执行。
3. 中午：显示任务结果，返回排班界面。
4. 下午：继续安排与执行；上午消耗、地点变化和建设进度立即生效。
5. 晚间：盘点、家庭对话、展示明日待办，回家电车自动充满。
6. 次日：倒计时减少一天，推进订单、地点与社会状态。

夜间首版不安排自由任务。空闲时段可休息；不因未填满排班弹出失败提示。查看地图、库存、新闻和编辑排班不消耗行动时间。教学由首次遇到对应功能触发，B/C均能覆盖。

## 4. 家人任务与运输

每个时段作为一段行动预算。短任务可以顺路合并，长任务需要跨时段或分阶段完成。任务确认前显示预计完成时段，不能隐藏跨日占用。

| 任务方向 | 常见人员条件 | 说明 |
|---|---|---|
| 步行采购、收小件快递 | 1名成人 | 受可携带量限制 |
| 集中采购、取建材 | 司机；重型装卸另需男性参与者 | 占用车辆，受载货量限制 |
| 物资清点、储藏、订单管理 | 1名成人 | 可由不同家人承担 |
| 重型储藏架搬运、院门安装 | 主角与父亲 | 两人同一阶段共同投入 |
| 通信检查 | 伴侣优先，其他家人可协助 | 基于既有电台和天线，不产生无限覆盖 |
| 护理物资检查 | 母亲优先 | 基于护士背景，不开放无依据的处方或治疗能力 |
| 专业电气安装与验收 | 已预约技术人员，家中留1名成人配合 | 购买设备不能跳过安装条件 |

所有成人均可整理、采购和交流；仅在任务卡明确要求时限制参与者。受伤或不可用人员不能派出。

多站出行使用同一队伍和同一辆车，各站按顺序结算。总耗时包含道路往返、地点办理和已知排队；载货累积计算，油电按实际完成路段扣除。首版不在中途自动更换队员或车辆。

确认前拦截已知的超时、超载、资金不足和能源不足。途中新增封路或延误时展示可选的缩短路线、取消后续站点或返回；已完成交易保留，未执行任务不发放收益。不能让车辆无提示地陷入永久无法返回的状态。

| 剩余天数 | 网购规则 |
|---|---|
| 9—6天 | 正常接单；预计1—3天到货 |

## 7. 工程清单

工程进度与材料支出分阶段保存。完成一个阶段后才扣对应材料并更新进度；任务失败不无条件吞掉整套设备。房屋空间以现有户型V0.5为准：地下室储藏，二层通信书房，三层服务器房与储能配电房，屋顶已有光伏及天线。

| 编号 | 项目 | 阶段 | 结果 |
|---|---|---|---|
| BUILD-01 | 院门与院墙加固 | 检查 → 选择局部或整体方案 → 备料 → 搬运施工 | 改善对应薄弱部位；不是绝对安全 |
| BUILD-02 | 墙外光伏扩建 | 确认空地使用 → 勘察预约 → 订设备 → 搬运安装 → 专业验收 | 完工后增加后续发电能力，附带院外维护需求 |
| BUILD-03 | 地下室储藏改造 | 检查返潮 → 腾挪垫高 → 安装储藏架 | 改善储藏条件与容量 |
| BUILD-04 | 应急储水 | 检查 → 购设施 → 安置 → 注水 | 容器与实际水量分别保存 |
| BUILD-05 | 通信与备用系统检查 | 检查现有设备 → 获取缺件 → 修复 → 测试 | 保存测试结果与可用功能 |

工程不要求全部完成才能通关。材料不足可采购，人员不足可改期，工人取消可保留设备与进度。光伏具体规模继续沿用待核算状态，不因本章确认而把此前8＋4kWp草案改成定稿。

## 8. 事件清单与触发

每日最多一项需要调整排班的重要随机事件。普通新闻、到货通知与短对话不占此名额。已发生的重要事件保存结果，存读档不重新抽取；条件满足的未处理任务仍可留在待办。

| 编号 | 事件 | 类型 | 触发与选择 |
|---|---|---|---|
| EVT-01 | 地下室的潮痕 | 必达检查 | 初次清点发现，选择腾挪或投入储藏改造 |
| EVT-02 | 墙外那片空地 | 条件剧情 | 房屋检查后父亲提议，查看条件或暂缓扩建 |
| EVT-03 | 师傅只能明天来 | 条件事件 | 预约施工后出现，留人配合或改约 |
| EVT-04 | 最后一批储藏架 | 随机机会 | 五金店开放且项目未完成，取货或放弃 |
| EVT-05 | 快递没有再更新 | 订单事件 | 延迟阶段的运输中订单，等待、查询或自取 |
| EVT-06 | 邻居想一起订货 | 随机机会 | 已走访邻居，可拼单并承担搬运安排 |
| EVT-07 | 路口多了一道检查 | 日期/道路事件 | 后期已知路线时间增加，可绕行或缩短计划 |
| EVT-08 | 母亲重新核对药箱 | 人物任务 | 四人团聚后，解锁护理物资缺口提示 |
| EVT-09 | 电台里陌生的声音 | 条件剧情 | 通信检查后，区分官方接收信息与未核实传言 |
| EVT-10 | 老板取消了送货 | 条件事件 | 后期未完成建材配送，自取、改期或取消 |
| EVT-11 | 车辆的小问题 | 条件事件 | 检查车辆后提示维护事项，维修或调整出行 |
| EVT-12 | 街上的灯还亮着 | 固定夜间剧情 | 最后准备日，家庭收尾与外界异常并置 |
| EVT-13 | 紧急广播 | 固定章末 | Day 12、剩余0天，仅触发一次 |

局部险情提供排队失序、急救车辆经过、临时封路等线索。玩家可撤离或改变计划。首版不安排随机感染、无提示死亡或提前战斗。

## 9. 每日剧情骨架

以下为剧情提纲，不是逐句正式剧本。固定日程保证社会变化连续，工程与互助剧情根据行为插入。错过一项采购机会不会抹去此前已完成事项。

| Day/剩余 | 固定叙事 | 操作重点 |
|---|---|---|
| 3 / 9 | C线：两人的第一顿早饭，打开地下室，父母抵达 | 安全屋、库存与排班入门；下午开启采购 |
| 4 / 8 | B线：围着清单的家庭会议；C线补充采购后的共通对话 | 两线均完成地图、路线、车辆与物资包教学 |
| 5 / 7 | 家庭讨论长期需要，父亲提起院门和墙外空地 | 选择工程、预约技术人员、正常网购 |

| 8 / 4 | 药店和超市出现限购，店员解释得越来越简短 | 最后接单日，查缺补漏、处理关键材料 |

章末表现先是广播打断家庭日常，再是简短对话与静默。广播文字需保持正式克制，强调当前措施与公众安排，不解释尚未揭示的感染秘密，也不宣布所有服务立即停摆。

## 10. 结算与存档接口

结算按食品、水、医疗卫生、能源、房屋、交通、通信和关系分别展示成果与缺口，不压缩成一个总分。未完工程、滞留订单与延期约定也列出，提醒玩家这些会继续存在。

跨章节最小状态：

- 当前Day、倒计时、时段、路线来源、当前章节和教学记录。
- 四人可用状态、行动分配、位置和当天任务结果。
- 库存、应急储备、资金、储藏容量及日常/封存区分。
- 两车位置、占用、载货、剩余油电和维护状态。
- 地点营业、供货、价格阶段、道路通行与访问记录。
- 订单付款、配送、领取和退款状态。
- 工程阶段、材料投入、预约、完工和测试状态。
- 关系变化、事件已触发标记及事件结果。

日期事件、路线初始化、到货、工程完工、夜间充电和章末结算均只执行一次。进入第三章复制或延续同一份状态，不重新生成库存与地图。

## 11. 验收与后续制作

### 验收场景

1. C线Day 3进入、B线Day 4进入，分别完成9/8个准备日并在Day 12触发广播。
2. C线父母上午不可排班、下午可排班；两线教学均完整，库存初始化不重复。
3. 两名男性协作施工时不能同时外出，同一辆车不能被两队占用。
4. 多站路线拦截已知超时、超载、资金或能源不足；途中变动只结算已完成部分。
5. 正常水电不误扣封存储备；储水受容器限制；只有回家的电车夜间补满。
6. Day 8可按规则下单，Day 9起不能新增订单；到货、自取和退款不重复执行。
7. 工程暂停保留进度，未验收光伏不增加发电能力，缺少全部工程也能进入第三章。
8. 随机事件不重抽、不阻断教学，不产生无提示重大损失。
9. 在上午确认前、途中选择后、晚间结算后存读档，库存和事件结果均一致。
