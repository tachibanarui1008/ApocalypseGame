# 第二章地图视觉样式 V0.5

本次调整地图呈现，不改变城镇道路、建筑位置、地点入口或V0.4距离矩阵。

## 视觉调整

- 底图：从浅色地表改为与工业UI协调的深灰绿地表；建筑轮廓降低对比，院落和农田保留细微色差，运河改为低饱和青灰。
- 标记：取消蓝底白色单字，使用房屋、篮筐、医疗十字、列车、包裹、工具、锚等14种细线图标。
- 状态：普通地点用灰绿线条；悬停和选中用浅绿强调，选中路线同样使用浅绿。
- 名称：安全屋、便民商店与卫生服务点直接显示名称；其余地点悬停显示完整名称，点击可查看详情。
- 密度：缩小地图时隐藏院门、墙外空地及部分拟设功能点的密集标记；地点表继续提供全部14地点。
- 移动：步行与车辆图标使用同一套线条、描边与配色。

## 文件与生成

原TOWN_MAP.svg/PNG保留为布局参考。游戏使用单独的town_map_game.svg/PNG，原图的可通行道路与建筑几何沿用，不把颜色调整当作新的地理设定。

运行tools/style_town_map.py生成底图、14地点三种状态的SVG/PNG图标、路线层和移动标记。tools/build_town_routes.py在重新生成距离数据后会同步生成此视觉样式，避免路线颜色退回旧版。

macOS使用系统Python与Homebrew Cairo时，可运行：

    DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib python3 tools/style_town_map.py

游戏运行本身不需要Cairo；App包含已经生成的PNG资源。地图图标点击区域没有额外按钮底色或文本徽章，保持与地物的对应。
