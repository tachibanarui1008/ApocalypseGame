# 家庭无线电与屋顶天线设定 V0.1

日期：2026-10-08。用于末日游戏的民用防灾设备设定，不新增第一章通话剧情。手持电台沿用已选FT-65R；本轮补充固定台、天线及其能力边界。

## 1. 给非专业读者的解释

手持电台像一部不依赖手机基站的对讲机。两端必须有相容的设备、使用同一约定频道，并能互相收到信号。它不因为拥有天线就能拨打手机，不能自动联系任意无线电设备。

屋顶天线相当于把收发电波的位置移到更高、更开阔的地方。它改善遮挡与天线效率，可能让以前难以联系的位置变得可联络；不凭空制造发射功率，也不代表有一个固定的“信号范围圆”。城市建筑、地形、天线安装、馈线损耗和对方设备都会影响通话。

“听见对方”与“双向说得通”不同。家中固定台的发射功率可能更高，但远处手持机仍只有自己的发射能力。屋顶天线也能改善家中接收，这是比简单加大发射功率更适合家庭方案的原因。

## 3. 屋顶与走线

户型草图将天线放在北侧服务平台靠东北角，光伏集中在南向主坡面，减少遮挡与检修冲突。图中的位置是空间关系草案，日照、风荷载和真实屋顶结构仍须核算。

天线基座使用约1.5m短桅杆作为初稿，而不是在住宅上建大型通信塔；天线本体另约1.7m。桅杆和地网杆不占用走道，不妨碍屋顶出口。馈线从东侧独立线路走向二层书房，图上虚线只表示路径，不表示可在任意位置穿孔。

设备故事中须具备固定件、防水进线、馈线应力释放、适配接头、入口处浪涌保护，以及由专业人员设计的建筑防雷与等电位连接；不要画成把线绕在栏杆上就能用。与光伏直流线及逆变器保持合理分离，避免相互干扰。设备柜留出散热空间，线路不妨碍住宅的门窗和逃生。

雷暴天气暂停使用并执行既定隔离方案；不把简单拔一根线描述为完整防雷保护。角色不在雷雨中上屋顶调整天线。

## 4. “广播”分成三种

| 玩家可能理解的行为 | 这套设备能否做到 | 正确写法 |
|---|---|---|
| 对家人的电台说话 | 可以，设备及频道相容、许可条件满足且链路可用时 | “呼叫家中固定台”“与外出小队通话” |
| 几个本地电台按约定时段交流 | 可以，仍需相容设备与合法运行条件 | “定时联络”“互通消息”，不宣称任何居民都能听见 |
| 像广播电台一样向所有收音机播放新闻/音乐 | 本方案不承担此功能 | 不写成“屋顶天线向全城广播” |

如果要向附近居民发出不依赖他们携带电台的通知，可以另设普通院内扩音器，传播的是声音、覆盖有限。第一章不新增这个设施；后续群像需要时再讨论。

现实中国的业余无线电设备使用受到许可与用途规则约束，不能未经批准进行广播或通播。项目所在“龙国”仍以现实民用管理逻辑作参考；尚未确定的操作能力验证、台站执照、呼号、频段及运行参数继续列为待定，不伪造许可记录或因“应急”默认所有限制消失。

## 5. 联络范围与情节约束

- **家附近：** 电台可以成为备用联络方式，但房屋、楼层和地形仍会形成盲区。
- **社区与较远地点：** 固定台加屋顶天线提供更好的尝试条件；正式地图完成后按遮挡、地势和对方设备给出可通/间歇/不可通状态，不先规定一个万能公里数。
- **依靠中继：** 仅在本地相容中继确实存在、获准使用、仍有电源与回传或转发条件时可能扩大覆盖；不能把别人维护的中继当作永远在线的自有设施。
- **沪海—庐州：** 本方案不保证数百公里直接通信，原第一章两地手机联络保持原样。若未来需要跨区域无线电，短波、卫星或多站接力应各自另做设备、权限和传播设定。
- **不能自动中继：** FTM-6000R在本方案中是普通固定收发台，不自动转发周围所有电台的信号。增加真正中继须另行选型与许可。
- **电量与维护：** 电台、备用电池和充电器都有有限能源；固定台待机、发射和充电分开计算。不直接将“50W射频输出”当成整机从电池取用的功率。
- **信息公开性：** 普通FM语音不设为加密私聊，有相容设备的人可能听到；后续故事可据此保留库存与位置披露的现实代价。
