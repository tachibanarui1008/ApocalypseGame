# 《末日游戏》第一章正式剧本 V1.0
## 第一章：晦暗阴云
**Chapter 01 · Clouds Before the Fall**

**文档性质：第一版完整剧情审定稿**  
**游戏形式：Galgame式视觉小说**  
**背景：2030年，龙国，沪海市—庐州市**  
**叙事视角：第二人称，玩家扮演主角**

> 灾难发生之前，没有人会知道，自己刚刚度过的究竟是怎样寻常的一天。

### 一、第一章的叙事基调

我建议将《晦暗阴云》定位为一部带有现实主义色彩的心理恐怖短篇，而不是传统的丧尸惊悚故事。

真正的恐怖不应来自不断出现的怪物，而应该来自三个层次：

**第一层：日常生活中的异常。**

拥挤的地铁、正常营业的便利店、手机上的新闻推送、公司里的工作安排。一切依然有序，但某些细节已经开始不对劲。

**第二层：信息和现实之间的错位。**

新闻仍然讨论肺炎，医院已经提高警戒等级；官方仍然努力维持秩序，普通居民却开始囤积物资。玩家不知道究竟该相信哪一部分。

**第三层：无能为力。**

尤其是A、D路线。主角并非完全没有行动，却始终无法准确判断自己还剩多少时间。

恐怖情绪应当在长时间的平静中积累，到悲剧发生时才短暂爆发。

B、C路线则有所不同。它们虽然仍然笼罩着不安，但更多表现为返乡途中的疲惫、情侣之间的相互依靠，以及一家人重新团聚的温暖。

### 二、章节与分支结构

本稿采用**六个主叙事节点、四条完整路线**。各路线的日历长度不同，不强行要求在同一天结束。

| 内容 | 剧情定位 | 结局 |
|---|---|---|
| 共通线 | 日常生活、异常新闻、医院朋友 | 第一次选择 |
| A路线 | 准备充分却误判撤离时间 | BAD END《昨日重现》 |
| B路线 | 家庭提前采购，稍晚返乡 | 《长路归乡》 |
| C路线 | 情侣尽早行动，提前返乡 | 《长路归乡》 |
| D路线 | 延误准备，被困城市公寓 | BAD END《围城》 |

**所有路线均采用纯视觉小说表现。**

A、D在结局处结束，不解锁生存数值界面。

B、C在成功抵达城郊安全屋后，解锁共同成就《长路归乡》，进入第二章《风暴前夜》。

第二章才正式开始逐步解锁行动力、物资、车辆、地图等系统。

以下是完整剧本正文。场景中的 `BG` 是背景图编号，`CG` 是关键剧情插画编号，末尾附有相应的美术描述。

## CH01-A01｜新型肺炎

**时间：Day 1，08:30**  
**背景：BG-04 地铁站台**

你打开新闻软件。

搜索栏里输入了“不明原因肺炎”。

搜索结果很快出现。

最新的一条来自龙国卫生主管部门。

【新闻】

**《关于近期部分地区不明原因肺炎病例的情况通报》**

> 近期，部分地区报告了由新型病原体引起的肺炎病例。有关部门正组织开展流行病学调查、病例救治及病原学研究。
>
> 目前，相关病例的临床表现及传播特征尚在进一步调查中。建议公众保持良好卫生习惯，及时关注官方发布的信息。

你看完通报，又往下翻了几条新闻。

大部分媒体都采用了相似的标题。

“新型肺炎”。

“加强个人防护”。

“相关部门正在调查”。

你对这些词并不陌生。

几年前，人们曾经反复听到过类似的提醒。

当时许多人的生活被改变了很长一段时间。

想到这里，你决定先买些口罩。

【购物软件】

搜索：医用外科口罩。

商品页面加载出来。

你愣了一下。

一盒平时二十多元的口罩，现在标价已经超过一百元。

有几家店铺甚至显示售罄。

**主角：** “操，怎么又涨成这样了。”

你又翻了几家。

价格都差不多。

犹豫片刻，你还是买下了几盒口罩，又添了些消毒用品。

【手机提示】

订单已提交。

预计后日送达。

地铁进站的提示音响起。

你跟着人群向前移动。

车厢里有不少乘客已经戴上口罩。

一个年轻人正在和朋友聊天。

**乘客甲：** “不会又要开始吧？”

**乘客乙：** “谁知道。反正口罩先备着。”

**乘客甲：** “我妈刚才还让我少坐地铁。”

# 第五部分：D路线
## BAD END 02《围城》

**路线主题：当生活的惯性变成牢笼。**

D路线不应简单地表现为主角愚蠢、懒惰或拒绝接受现实。

事实上，在最初的几天里，主角对局势的判断与大多数普通居民并没有明显区别。

继续工作，照常生活，等待更明确的信息——这些都是可以理解的行为。

这条路线最恐怖的地方在于：

**主角并不是突然发现自己陷入绝境，而是在无数个看似还可以忍受的日子里，逐渐失去了离开的可能。**

与A路线的短暂、激烈不同，D路线应当漫长、安静、压抑。

我建议采用一套统一的美术规范，而不是每张图使用不同风格。这样我们以后可以通过生图工具分批制作，同时保持人物和建筑的一致性。

## 一、统一美术风格

**2026-10-08风格修订：** 参考《无悔华夏》的概括造型和淡墨色彩；以VISUAL_BIBLE V0.2为当前制作准则。人物无五官或仅淡笔勾勒，禁止穿孔饰品，背景同样简笔化；不照搬参考作品具体角色。住宅空间及无线电位置见SAFEHOUSE_LAYOUT、RADIO_PLAN。

**项目美术代号：Apocalypse — Quiet Ink Sketch**

| 项目 | 统一标准 |
|---|---|
| 画面比例 | 16:9 |
| 目标分辨率 | 1920×1080 |
| 核心画风 | 简笔淡墨、低饱和色块与留白，人物背景笔触一致 |
| 建筑风格 | 现代中国城市与城乡结合部 |
| 色彩 | 低饱和、淡墨层次、少量自然光色块 |

### 整体视觉要求

游戏不能一开始就显得像末日世界。

沪海市的建筑、道路、车辆和商店应当正常且具有生活气息。

恐怖感主要通过细节形成。

例如，同一个地铁站，初期熙熙攘攘，后续可能因为部分线路停运而变得空旷。

同一套公寓，最初温暖明亮，到了D路线末期，窗帘紧闭、生活用品散乱，逐渐失去居住感。

这种变化应当依靠**场景复用与状态差异**实现，而不是简单给所有图片添加阴暗滤镜。

# 第七部分：关键剧情CG

背景图与剧情CG应该区分。

背景图用于角色对话，通常需要预留立绘和文字显示空间。

CG则用于剧情高潮，可以采用更加电影化的构图。

## CG-01｜《昨日重现》

**用途：A路线结局插画**

> 2030年，一处混乱过后的高速公路服务区停车场，傍晚天空逐渐暗下。镜头几乎贴近地面，前景是一部掉落在沥青路面上的智能手机，玻璃屏幕出现裂纹，屏幕发出微弱冷光。手机旁边散落着一个购物袋和两瓶饮用水。背景中有模糊的汽车尾灯、远处的人群剪影和一辆仍停在充电区的新能源汽车。景深很浅，焦点集中在手机上。整体克制、悲伤、安静，不出现明显血腥画面。

**特别要求：**

手机上的导航界面、目的地和“217公里”不要依靠AI直接生成文字。

我们应当在Ren'Py中叠加真正的导航UI。

这样既能保证文字准确，也方便以后根据剧情调整数值。

### 推荐镜头表现

先展示完整场景。

随后镜头逐渐向手机靠近。

最后整个画面只剩下手机导航。

背景声音慢慢消失。

黑屏后出现：

**BAD END 01：《昨日重现》**

# 第八部分：第一章游戏化规范

剧情基本完成后，还需要确定一些重要的实现原则。

## 1. 第一章只显示叙事UI

- 角色立绘。

# 第九部分：剧情连续性与定稿校验

第一版完成后，我对设定做了几项内部核对。

### 1. 感染潜伏期

我们之前确定感染潜伏期为2天至6个月以上。

因此，A路线客车事件中的多名异常乘客，应当被设定为**此前已经感染、在途中陆续出现症状的人**。

他们在车内造成的咬伤不会让新受伤者在几分钟内立即转化。

这也是A路线需要遵守的重要世界规则。

2026-10-08用户决定：A05中关于客车乘客此前感染的信息按“你也许再也不会知道：……”的修订文字向玩家呈现，保留在正文旁白中。这是叙事层面的补充，不表示主角后来获得了该信息；主角直到死亡都不知道客车上究竟发生了什么。此前“仅保留在开发者设定、不播出”的制作要求不再适用。

### 2. 武警的行动

A路线中，临时驻守的武警并非没有反应。

他们尝试隔离客车周围区域、组织疏散和维持秩序。

但由于现场人数众多、道路拥堵，以及感染者与普通逃跑旅客混杂，临时警戒线最终被冲散。

正式制作时不应将其画成数量庞大的感染者军团瞬间击败完整的军事阵地。

### 3. D路线的基础设施

D路线虽然持续到Day 25，但城市并非已经完全断水断电。

主角所在住宅楼出现的是局部供水故障、短时停电和配送困难。

这符合我们之前确定的渐进式社会失序原则。

D路线最后的危险来自**楼内局部突发事件、撤离条件恶化及感染者侵入**，而不是因为整个沪海市在几天之内完全失去所有基础设施。

### 4. 家庭住宅关系

三套住所继续保持明确区分：

| 住所 | 位置 | 日常使用者 |
|---|---|---|
| 沪海市公寓 | 沪海市 | 主角与伴侣 |
| 庐州市区住房 | 庐州市区 | 父母 |
| 城郊安全屋 | 庐州市城郊 | 家庭共同备用住所 |

安全屋是此前因小地震风险而购置、修缮的住宅，并非为丧尸疫情专门建造。

### 5. 具体日期与人物姓名

目前第一章只使用Day 1等相对日期。

2030年的具体月份尚未确定，因此暂不在背景中加入明确的秋叶、冬雪或季节性服饰。

2026-10-08人物资料初稿：主角陈知远26岁，伴侣林晚宁24岁，父亲陈建川56岁，母亲周慧敏54岁。主角与伴侣年龄为用户指定，名字、父母具体年龄及外貌由本轮授权拟定，详见VISUAL_BIBLE.md；外貌待参考图审看。医院朋友姓名尚未确定。

正文继续使用主角、伴侣、父亲、母亲等稳定角色标签；后续显示名按人物资料映射，不批量改写第二人称旁白。

## 第一版剧情的最终定位

我希望《晦暗阴云》给玩家留下的不是“原来选错了就会死”，而是一种更复杂的感觉：

**所有人都在尝试理解发生了什么，但不是每个人都能在正确的时间作出决定。**

A路线的主角曾经准备离开，只差最后217公里。

D路线的主角一直认为生活还会恢复正常，直到家变成了无法逃离的地方。

而B、C路线之所以能够成功，并非因为主角提前知道灾难的真相。

他们只是比其他路线更早选择行动，并且恰好拥有可以返回的故乡、相互信任的伴侣，以及愿意共同准备的家人。

这也为第二章《风暴前夜》留下了一个重要的转变：

**第一章讲述的是他们如何回家；第二章讲述的是他们如何准备守住这个家。**

目前这份是**完整的第一版审定稿**，还不是不可修改的最终剧本。我们已经完成了四条路线的主要场景、对白、结局、成就以及全部背景图描述，可以据此逐场审核，再开展人物立绘和实际背景图绘制。
