# 第一章人物、住宅与设备视觉设定 V0.2

日期：2026-10-08。本轮用户指示替代V0.1的半写实人物与背景方案；名字、年龄和既有剧情不变。参考《无悔华夏》的概括造型、淡墨与传统色彩气氛，同时采用用户明确要求的无五官/淡笔五官、简笔画人物及背景。不照搬该作具体人物、古代服饰或历史建筑。

## 1. 当前统一画风

**项目美术代号：Apocalypse — Quiet Ink Sketch。** 少量线条、低饱和色块、淡墨与留白，保留普通现代城市和家庭生活的辨识度。人物与背景使用同一笔触，不再使用精细动漫脸、写实皮肤、镜面材质和电影级光影。背景继续16:9、目标1920×1080。

人物默认没有明确眼睛、鼻子、嘴。确需方向感时，仅用低对比度的一两笔提示侧脸或垂眼；不画精致眼珠、睫毛、唇色、写实鼻梁、夸张脸红。脸部不要涂成令人不安的白面具，用与手部一致的浅色平涂。情绪由头部方向、肩背、手势、距离、停顿和对白表达，保持故事主体性。

**四人均无耳钉、耳环、鼻环、唇环及其他穿孔类装饰。** 取消V0.1伴侣银色耳钉。人物辨识靠发型、身形、衣服和姿态。主角细框眼镜可保留为很淡的两笔轮廓，不能借眼镜画回完整眼睛。

背景减少纹理和物件密度，但保留关键空间关系：道路、门窗、楼梯、院墙、充电线与出口。恐怖依靠静默、留白、暗部、重复构图和失序的人影；不把无五官本身当成怪物符号。正常居民与感染者都用同一造型规则，靠动作和情境区分。

统一色板初稿：纸白/暖灰底色，墨灰线条，灰蓝与鼠尾草绿用于衣物，低饱和紫保留情侣车辆辨识；归乡灯光用少量赭黄，警示灯少量暗红。白天正常有生活气息，末日不从开场就满屏废墟。

## 3. 背景制作规则与既有文本衔接

ART_PROMPTS.md保留26个背景、3个CG的编号、地点、物件、时间和情绪；统一风格字段已同步为简笔淡墨。以后生图以本文件为全局风格约束，原稿快照中的半写实词只代表历史基线。

线条有轻微手绘差异但结构清楚；大面积墙面与天空留白，用很少的明暗建立空间。小店与车流仅画到能理解生活状态；人物立绘之外的路人是淡色概括轮廓。屏幕、导航、新闻、车牌和招牌文字后期叠加。

公寓的日夜/困守版本共用构图和家具位置；A线出城道路拥堵，C线通畅，必须制作状态差异。车辆保留车型整体轮廓及颜色即可，不把背景变成汽车广告。CG仍以手机、空杯、家中灯光等物件承载故事，不改为人物面部特写。

## 4. 沪海两居室公寓

约75㎡仅作构图预算：主卧约15㎡，次卧兼书房与客房；一处卫浴，小型开放厨房与餐厅相连，客厅有生活阳台。米白墙、浅木家具、灰色沙发，普通租住家庭的生活痕迹。

先确定床头手机、窗帘光带、两人对坐餐桌、客厅沙发、电视和玄关的相对位置，再制作BG-01/02/05/24/26与CG-02。次卧有普通书桌和收纳柜，无线电随身设备平时收在柜内，不画专业机房。月份、朝向和楼层未锁定。

## 5. 三层中式安全屋与户型草图

现代江淮中式民居：灰白墙、深灰瓦坡屋顶、适度出檐、深色窗框、木色门廊、普通砖院墙和金属院门，屋顶有光伏与细长民用天线。造型简笔化，不能变成宫殿或军事堡垒。

草图按地上建筑外包预算11m×10m，每层约110㎡，三层合计约330㎡；地下室11m×8.2m约90㎡；院落另计约100～150㎡。这些不是净使用面积；院落图只示意车辆与出入口，不与楼层同比例。墙厚、结构、楼梯尺寸和净面积后续细化。

- 地下室：固定楼梯、食品、水与用品储藏、工具维护，留通道；不设为默认地震避难室。
- 一层：南侧主入口、玄关与公共通道、客厅、餐厅、厨房、卫浴、临时客房；厨房有通往室外的侧门。
- 二层：父母卧室、情侣卧室、卫浴、洗衣储物及书房；书房放Mac mini、固定电台、供电与日志。
- 三层：客房、多功能房、杂物间、卫浴；楼梯与卫生间同位置叠放，楼梯继续至屋顶出口。

保持既有30kWh储能不变。草图不承诺开局光伏12kWp全部建成；组件面积、遮挡与天线风荷载须后续核算。BG-19/20、BG-21及CG-03共用这一套建筑参考，内部窗与楼梯必须能对上外观。

## 6. 车辆修订

### VEH-01 紫色小米SU7

替代V0.1小鹏P7方案：选择2024第一代小米SU7标准版、霞光紫。厂商初代配置表包含标准版及霞光紫选装色。普通日常轮圈，正常家用外观，不用Ultra赛道套件或夸张尾翼；保留SU7溜背轿车轮廓、相同代际的灯组。

初稿购车史沿用2028年购买二手车，2030年车龄约六年；价格、贷款、实际里程和电池健康不擅自填入。游戏色板把金属紫概括成低饱和紫色块，保留使用痕迹。原剧情97%/96%/98%出发电量和途中补能不改；工况续航不等于剧情保证距离，不默认可给住宅反向供电。

### VEH-02 白色路虎SUV

替代V0.1 RAV4方案：选择2020款路虎发现运动版，R-Dynamic SE性能科技版，白色车身。Discovery Sport属于发现运动系列，与大型路虎发现及揽胜系列区分；绘图采用对应代际参考，不混用前脸。

2030年车龄约十年，父母长期使用，维护史与购置方式待家庭经济核算。普通白漆、少量旧车划痕、正常家用轮胎。其汽油动力版本不写成纯电车，也不因车标宣称永久可靠或能越过任何地形；维修、零件、油量及电气系统状态后续独立管理。
